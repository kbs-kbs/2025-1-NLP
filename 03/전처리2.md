## 보강 — 전처리 함수 정리

교안(9장 2절)에서 다룬 전처리 관련 함수를 계열별로 묶으면 다음과 같다. "11개 중 5개" 유형으로 코드 빈칸을 채우는 문제가 나왔다.

### 1. 결측치 확인·처리

| 함수 | 역할 |
|---|---|
| `isnull()` / `isna()` | 결측치 여부 확인 |
| `isnull().sum()` | 열별 결측치 개수 |
| `isnull().sum() / len(df)` | 결측치 비율 |
| `dropna(how='all')` | 모든 값이 NaN인 행 삭제 |
| `dropna(how='any')` | NaN이 하나라도 있는 행 삭제 |
| `fillna(0)` / `fillna(df.mean())` | 특정 값·평균으로 채우기 |

### 2. 토큰화·불용어·어간/표제어

| 함수 | 역할 |
|---|---|
| `sent_tokenize(text)` | 문장 토큰화 |
| `word_tokenize(text)` | 단어 토큰화 |
| `WordPunctTokenizer().tokenize(text)` | 아포스트로피까지 분리 |
| KoNLPy `Okt().morphs(text)` | 한국어 형태소 단위 토큰화 |
| `stopwords.words('english')` | 불용어 목록 |
| `PorterStemmer().stem(w)` / `LancasterStemmer()` | 어간 추출 |
| `WordNetLemmatizer().lemmatize(w, pos='v')` | 표제어 추출 |

### 3. 정규화

| 클래스 | 특징 |
|---|---|
| `MinMaxScaler()` | 0~1, 이상치에 민감 |
| `StandardScaler()` | 평균 0·분산 1 |
| `RobustScaler()` | 중간값·IQR 사용 |
| `MaxAbsScaler()` | 절댓값 0~1 |

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

scaler = MinMaxScaler()
X_train = scaler.fit_transform(X_train)   # 학습 데이터로 기준을 잡고
X_test  = scaler.transform(X_test)        # 테스트에는 같은 기준을 적용
```

### 4. 결측치 비율 결과를 문제 삼는 이유

- 교안의 점검 포인트: "결측치 비율에 대한 결과를 보여주고 문제점" → 결측치가 있는 상태로 학습하면 **오차가 커지고 예측이 편향**된다. 따라서 비율을 먼저 확인하고, 삭제·대체 중 무엇이 적절한지 판단해야 한다.
