## 1. 선형 회귀(Linear Regression)

- 가장 간단한 모델 중 하나. **연속된 변수**를 예측한다(집값, 실업률, 공부시간과 학점 등).
- 두 변수 사이의 관계를 분석하거나 값을 예측하는 데 쓴다. 지도 학습 중 **target이 연속형 변수**인 경우다.
- 종류
  - 단순 선형 회귀: 독립변수 1개 → `f(x) = wx + b`
  - 다중 선형 회귀: 독립변수 여러 개 → `y = a1x1 + a2x2 + b`
  - 다항 회귀(Polynomial Regression) 등
- **회귀(regression)의 어원**: 골턴(Francis Galton)이 아버지 키(x)와 아들 키(y)를 연구하며 최소제곱선을 적합했더니, 키가 큰 아버지의 아들은 평균보다 크지만 아버지만큼 크지는 않았다. 즉 아들의 키가 **평균으로 되돌아갔다(regressed)** → 이 직선을 회귀선이라 부른 것.

### 손실 함수 — 최소제곱법

- 데이터를 2차원 공간에 찍고, 데이터를 가장 잘 설명하는 **직선(또는 곡선)** 을 찾는 문제.
- 직선과 데이터 사이의 간격을 **제곱해서 합한 값**이 손실 함수(loss/cost function)다.
- 이 값을 최소로 하는 w, b를 찾는 것이 학습이며, 경사 하강법으로 갱신한다.

```python
from sklearn.linear_model import LinearRegression
from sklearn import metrics
import numpy as np, pandas as pd
from sklearn.model_selection import train_test_split

dataset = pd.read_csv('weather.csv')                       # MinTemp / MaxTemp
X = dataset['MinTemp'].values.reshape(-1, 1)
y = dataset['MaxTemp'].values.reshape(-1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

regressor = LinearRegression()
regressor.fit(X_train, y_train)

y_pred = regressor.predict(X_test)
print('평균제곱오차(MSE):', metrics.mean_squared_error(y_test, y_pred))
print('루트 평균제곱오차(RMSE):', np.sqrt(metrics.mean_squared_error(y_test, y_pred)))
```

- 결정 경계는 `plt.plot(X_test, y_pred, color='red')`로 데이터 위에 직선을 그려 확인한다.

## 2. 로지스틱 회귀(Logistic Regression)

- **0과 1을 예측**하는 이진 분류(Binary Classification) 모델. 이름은 회귀이지만 분류에 쓴다.
- 선형 회귀는 **직선**을 출력하고, 로지스틱 회귀는 **S자 곡선**을 출력한다.
  - 선형 회귀: 연속적인 값(수치) 예측 → 집값, 온도, 판매량
  - 로지스틱 회귀: 범주(0 또는 1)의 **확률** 출력 → 스팸메일, 질병 진단, 부품 고장 확률, 보험 위험도
- 분류에서 선형 회귀의 정확도가 떨어지는 부분을 보완하려고 S자 곡선을 이용한다.

| 함수 | 특징 |
|---|---|
| **시그모이드(Sigmoid)** | 출력을 0~1로 변환, 이진 분류에 사용. 여러 개를 쓰면 정규화가 안 되어 효율이 떨어진다 |
| **소프트맥스(Softmax)** | 여러 클래스 분류에 특화. 출력값이 정규화되어 **합이 1**(확률) |

- 활성화 함수(activation function) = 입력 신호의 총합을 출력 신호로 변환하는 함수

```python
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn import metrics

digits = load_digits()                       # 8×8 이미지, 64차원
x_train, x_test, y_train, y_test = train_test_split(digits.data, digits.target, test_size=0.25, random_state=0)

logisticRegr = LogisticRegression()
logisticRegr.fit(x_train, y_train)

predictions = logisticRegr.predict(x_test)
score = logisticRegr.score(x_test, y_test)
print(score)

cm = metrics.confusion_matrix(y_test, predictions)     # 혼동 행렬
```

- 로지스틱 회귀는 **분류 결과에 대한 확신이 없을 때, 추가 데이터를 모아 재학습할 수 있는 환경**에서 쓰면 유리하다(교안 설명).
- 관련 개념: 이산형 변수, 최대 우도법(maximum likelihood), 카이제곱 검정.

## 3. 두 모델 비교 요약

| 항목 | 선형 회귀 | 로지스틱 회귀 |
|---|---|---|
| 출력 | 연속적인 수치 | 0~1 사이의 확률 → 0 또는 1 |
| 그래프 | 직선 | S자 곡선 |
| 손실 | MSE(평균제곱오차) | 교차 엔트로피 |
| 예 | 집값, 온도 | 스팸/정상, 발병 여부 |
| 사이킷런 | `LinearRegression` | `LogisticRegression` |

## 4. 시험 포인트

- 시그모이드·소프트맥스의 차이(이진 vs 다중, 합이 1인지)
- MSE와 RMSE의 의미와 계산
- 회귀 = 평균으로의 회귀라는 어원
- 경사 하강법으로 손실을 줄이는 방향으로 w, b를 갱신
