## 보강 — 결측치·데이터 용어 정리 (교재 9장)

### 용어 대응표

| 분야 | 행 | 열 |
|---|---|---|
| 수학 | 행(row) | 열(column) |
| 통계 | 레코드(record) | 어트리뷰트(attribute) |
| 인공지능 | 인스턴스(instance) | 속성·필드·차원(feature) |
| DBMS | 튜플(tuple) | 속성 — 그 외 카디널리티(행 수), 릴레이션(테이블), 엔티티 |

### 결측치 확인

```python
df.isnull()            # 셀별로 결측치 여부(True/False)
df.isnull().sum()      # 열별 결측치 개수
df.isnull().sum() / len(df)   # 열별 결측치 비율
df.describe()          # 기초 통계량
df.shape, df.info()    # 크기·자료형
```

- 비율을 보는 이유: 결측치가 **어느 열에 얼마나** 있는지에 따라 처리 방법이 달라지기 때문이다.
- 통계학에서 "유의미하다"는 판단 기준으로 흔히 **유의수준 0.05**(신뢰구간 95%)를 쓴다. 결측치 비율이 일정 수준(예: 10% 이하)이면 대체, 그보다 크면 열 삭제를 검토한다.

### 결측치 처리 선택 기준

| 상황 | 방법 |
|---|---|
| 데이터가 많다 | 결측치가 있는 **행 삭제** (`dropna()`) |
| 데이터가 적다 | **평균값·최빈값·앞뒤 값**으로 대체 (`fillna()`) |
| 특정 열의 값이 거의 없다 | **열 자체 삭제** |
| 모든 값이 NaN인 행 | `dropna(how='all')` |
| 하나라도 NaN이면 삭제 | `dropna(how='any')` |

### 시험에서 자주 묻는 코드

```python
# 결측치 개수 확인
df.isnull().sum()

# 결측치 삭제
df = df.dropna()

# 결측치 채우기(0 / 평균 / 최빈값)
df.fillna(0)
df.fillna(df.mean())
df['열'].fillna(df['열'].mode()[0])
```
